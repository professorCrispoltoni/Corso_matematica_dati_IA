Hai le etichette?

Che cosa può fare il modello

Programmazione tradizionale

dati+regole→risposte

Le regole le scrive una persona. Se cambia la situazione, qualcuno deve riscrivere le regole.

Machine learning

dati+risposte→regole

Si danno esempi con la risposta (le etichette): l’algoritmo ricava le regole. Con altri dati ricava altre regole.

consuma tanto   consuma poco   ◯ = la regola sbaglia. Linea tratteggiata: la media dei km/litro (9,97).
